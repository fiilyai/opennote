# AI · 科技热点速览

给一份「最近值得知道的几件事」，兼顾 **国际 + 国内**、覆盖 **AI / 科技 / 科技金融** 三个面，
每条一句话说清是什么 + 为什么值得看，附链接。
**这是 opennote 主动干活的招牌场景**：配进 `cron:` 里到点自动跑、把简报推给你（见 Day 8）。

> 下面命令里的 `<skill>` 指本 SKILL.md 所在目录（skills 菜单里有它的绝对路径），脚本在 `<skill>/scripts/collect.mjs`。相对路径按 cwd（`~/.opennote/notes/`）解析。

## 流程

直接动手，别长篇规划：

1. **采集候选**：跑脚本，它从两个池子拉候选、**已经跨源去重 + 粗分类**（每条前面标了 `[AI]`/`[科技]`/`[科技金融]`），分「国际 / 国内」两段吐到 stdout，清单已经在你上下文里：

   ```bash
   node <skill>/scripts/collect.mjs
   ```

   - 国际 = Hacker News 热榜（带 ▲点数）；国内 = 雷锋网/36氪/钛媒体/IT之家 的 RSS。
   - 调参：`--hours 24`（时间窗）、`--min-points 50`（HN 热度门槛）、`--limit 20`（每池条数）；
     换 HN 关键词直接跟在后面，如 `node <skill>/scripts/collect.mjs LLM 多模态`。
   - 某一段是「（本时段没采集到）」就如实说那边没扫到，别硬编。

2. **挑 + 写**：从候选里挑 **国际约 5 条 + 国内约 5 条**，**三类（AI / 科技 / 科技金融）尽量都覆盖到**，别一边倒、别全是 AI。取舍原则：
   - 优先真有信息量的（新模型/新产品/重要融资并购/政策），跳过软文、凑数稿、明显跑题的（脚本分类是粗的，以你的判断为准）。
   - 脚本已去重，但**国际和国内可能是同一件事的两种报道**，撞了只留一条（标注「中外都在报」更好）。
   - 每条写**一句话**：是什么 + 为什么值得看，别只抄标题。整体控制在手机两三屏内。

3. **输出简报**：直接把简报作为回复输出（定时任务会把它推给用户）。格式见下，纯文本友好、别堆 markdown 符号（最终会过一道 markdown→纯文本再进微信）。

4. **存档（可选）**：只有用户/任务明确要「存起来 / 记一笔」时，才把简报 `write` 到 `radar/{YYYY-MM-DD}.md`，方便日后回看趋势。默认只推送、不落盘。

## 简报格式

```
📡 AI·科技速览 · {YYYY-MM-DD}

🌍 国际
1. {一句话：是什么 + 为什么值得看}
   {链接}
2. …

🇨🇳 国内
1. {一句话}
   {链接}
2. …

（国际数据源：Hacker News 近 {时段}；国内：雷锋网/36氪/钛媒体/IT之家）
```

## 边界

- **没采集到候选**：如实说今天没扫到够分量的，别为凑数把低质条目硬塞进来，更别编造。
- **某一池子挂了**（网络/源故障）：用能拿到的那池照常出，注明另一池这次没取到。
- **候选明显跑题**（IT之家偶尔混进趣闻、搜 agent 搜出非 AI 的）：靠你的判断筛掉，宁缺毋滥。
- **想加源**：往 `collect.mjs` 的 `DOMESTIC_FEEDS` 里加 RSS（或加个新抓取分支），吐成同样的清单格式即可，本流程不用改。这也呼应 Day 9 接 MCP / 更多数据源的方向。
- **采集 ≠ 精读**：速览只到「一句话点评」。某条想深挖、存进知识库，那是 wiki-ingest 的活——把链接当成一次正常 ingest 收进去。
